# 3.1 Abordagem de Desenvolvimento

O VetAgenda será desenvolvido de forma **iterativa e incremental**. As seções do projeto serão produzidas por etapas, começando pela descrição do sistema e seguindo para os requisitos, modelos, banco de dados, protótipos e arquitetura.

Ao final de cada etapa, a nova seção será conferida com as anteriores para verificar se as informações estão de acordo. Quando houver algum problema ou inconsistência, a parte correspondente será corrigida antes de continuar para a próxima etapa. As alterações serão registradas no repositório do projeto.

Essa abordagem foi escolhida porque permite identificar e corrigir problemas durante o desenvolvimento, em vez de deixar todas as correções para o final. No modelo em cascata, uma alteração poderia exigir mudanças em várias partes já concluídas. Como o projeto será desenvolvido individualmente, não serão utilizadas cerimônias do Scrum, como reuniões diárias.
