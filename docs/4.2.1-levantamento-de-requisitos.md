# 4.2.1 Levantamento de Requisitos

## Como os requisitos foram levantados

Os requisitos do VetAgenda foram levantados por meio de uma entrevista simulada com Clarice, secretária de uma clínica veterinária. A conversa teve como objetivo entender como são realizados os cadastros, os agendamentos e o controle da agenda da clínica.

Também foram analisadas as necessidades apresentadas na descrição do projeto e no escopo definido na seção 4.1. Durante a entrevista, foram feitas perguntas sobre os dados dos tutores, animais e veterinários, além do funcionamento dos agendamentos, cancelamentos e reagendamentos.

## Da fala à necessidade

| # | Fala | O que é | Necessidade por trás |
|---|---|---|---|
| F1 | "Preciso manter os dados dos tutores organizados para conseguir encontrar as informações quando necessário." — Clarice, secretária | necessidade | cadastrar e consultar os dados dos tutores |
| F2 | "Um tutor pode ter mais de um animal, então preciso conseguir relacionar cada animal ao seu tutor." — Clarice, secretária | necessidade | cadastrar animais e relacioná-los aos respectivos tutores |
| F3 | "Preciso ter os dados dos veterinários cadastrados para conseguir marcar as consultas." — Clarice, secretária | necessidade | cadastrar veterinários |
| F4 | "Preciso informar o animal, o veterinário, a data e o horário quando marcar uma consulta." — Clarice, secretária | necessidade | registrar os dados necessários para o agendamento |
| F5 | "Não pode ter duas consultas para o mesmo veterinário no mesmo horário." — Clarice, secretária | regra de negócio | evitar conflitos de horário na agenda |
| F6 | "Quando uma consulta for cancelada, preciso que o horário fique disponível novamente." — Clarice, secretária | necessidade | cancelar consultas e liberar o horário |
| F7 | "Às vezes o tutor precisa mudar o horário, então preciso conseguir reagendar." — Clarice, secretária | necessidade | permitir o reagendamento de consultas |
| F8 | "Preciso conseguir visualizar os horários e saber quais consultas estão marcadas." — Clarice, secretária | necessidade implícita | consultar a agenda da clínica |

## Histórias de usuário

| # | História de usuário | Veio de |
|---|---|---|
| HU01 | Como **secretária**, quero **cadastrar um tutor**, para **manter os dados dos clientes organizados**. | F1 |
| HU02 | Como **secretária**, quero **cadastrar um animal e relacioná-lo ao seu tutor**, para **manter os dados dos animais organizados**. | F2 |
| HU03 | Como **secretária**, quero **cadastrar um veterinário**, para **poder relacioná-lo às consultas**. | F3 |
| HU04 | Como **secretária**, quero **agendar uma consulta**, para **organizar os atendimentos da clínica**. | F4 |
| HU05 | Como **secretária**, quero **consultar a agenda**, para **visualizar os horários e consultas marcadas**. | F8 |

## Requisitos funcionais

| # | Nome | Requisito | Veio de |
|---|---|---|---|
| RF01 | Cadastrar tutor | O sistema deve permitir que a secretária cadastre um tutor. | HU01 |
| RF02 | Cadastrar animal | O sistema deve permitir que a secretária cadastre um animal e o relacione ao seu tutor. | HU02 |
| RF03 | Cadastrar veterinário | O sistema deve permitir que a secretária cadastre um veterinário. | HU03 |
| RF04 | Agendar consulta | O sistema deve permitir que a secretária agende uma consulta informando o animal, o veterinário, a data e o horário. | HU04 |
| RF05 | Consultar agenda | O sistema deve permitir que a secretária consulte os horários e as consultas agendadas. | HU05 |
| RF06 | Cancelar consulta | O sistema deve permitir que a secretária cancele uma consulta agendada. | F6 |
| RF07 | Reagendar consulta | O sistema deve permitir que a secretária altere a data ou o horário de uma consulta agendada. | F7 |
| RF08 | Verificar conflito de horário | O sistema deve impedir o agendamento de duas consultas para o mesmo veterinário no mesmo horário. | F5 |

## Requisitos não funcionais

| # | Categoria | Requisito | Veio de |
|---|---|---|---|
| RNF01 | Usabilidade | O sistema deve apresentar os cadastros e a agenda de forma organizada e simples para facilitar o uso pela secretária. | necessidade da cliente |
| RNF02 | Dispositivo | O sistema deve funcionar em navegador, sem necessidade de instalação de um programa específico. | características da 4.1 |
| RNF03 | Desempenho | A consulta da agenda deve apresentar os resultados em até 3 segundos. | necessidade de agilidade no atendimento |

## Conferência com a 4.1

| Item do escopo (4.1) | Requisitos |
|---|---|
| O sistema permite cadastrar tutores. | RF01 |
| O sistema permite cadastrar animais. | RF02 |
| O sistema permite cadastrar veterinários. | RF03 |
| O sistema permite agendar consultas. | RF04 |
| O sistema permite consultar a agenda. | RF05 |
| O sistema permite cancelar consultas. | RF06 |
| O sistema permite reagendar consultas. | RF07 |

**Toda história tem requisito?** Sim. HU01 está relacionada ao RF01, HU02 ao RF02, HU03 ao RF03, HU04 ao RF04 e HU05 ao RF05.

**Todo requisito tem origem?** Sim. Os requisitos RF01 a RF05 vieram das histórias de usuário. Os requisitos RF06, RF07 e RF08 vieram diretamente das necessidades identificadas durante o levantamento.

**O que a conferência mudou?** A conferência confirmou que os itens definidos no escopo da 4.1 possuem requisitos correspondentes. Também foram detalhadas algumas regras da agenda, como o cancelamento, o reagendamento e a impossibilidade de marcar duas consultas para o mesmo veterinário no mesmo horário.

## Confirmação com a cliente

Durante a entrevista simulada, foram feitas perguntas direcionadas à rotina da clínica:

**1. Quais informações precisam ser cadastradas sobre o tutor?**

Clarice: "Preciso do nome, telefone e CPF para conseguir identificar e entrar em contato com o tutor."

**2. Quais informações precisam ser cadastradas sobre o animal?**

Clarice: "Preciso do nome do animal, espécie, raça, idade e do tutor responsável."

**3. Um tutor pode ter mais de um animal?**

Clarice: "Sim. Um mesmo tutor pode ter vários animais cadastrados."

**4. Quais informações precisam ser cadastradas sobre o veterinário?**

Clarice: "Preciso do nome, número do CRMV e especialidade."

**5. O que precisa ser informado para marcar uma consulta?**

Clarice: "Preciso selecionar o animal, o veterinário, a data e o horário da consulta."

**6. Pode haver duas consultas para o mesmo veterinário no mesmo horário?**

Clarice: "Não. O sistema precisa impedir esse tipo de conflito."

**7. O que acontece quando uma consulta é cancelada?**

Clarice: "A consulta deve ficar como cancelada e o horário precisa ficar disponível novamente."

**8. É necessário poder mudar o horário de uma consulta?**

Clarice: "Sim. Preciso conseguir reagendar quando o tutor pedir uma mudança."

**9. O que você precisa visualizar na agenda?**

Clarice: "Preciso ver os horários, os animais, os veterinários e a situação de cada consulta."

**10. Quem vai utilizar o sistema?**

Clarice: "Inicialmente, a secretária será responsável por utilizar o sistema."
